# Sample Output

## system_health_check.sh

Incluye:
- hostname
- kernel
- uptime
- memoria
- disco
- top procesos por CPU y memoria

## resource_report.sh

Incluye:
- información de CPU
- memoria y swap
- uso de disco
- directorios más pesados

## ports_and_processes.sh

Incluye:
- puertos escuchando
- procesos principales por CPU y memoria

## service_check.sh

Incluye:
- estado de un servicio
- logs recientes consultados con journalctl
