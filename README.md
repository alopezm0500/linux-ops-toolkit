# linux-ops-toolkit

Toolkit básico de operación Linux para revisar salud del sistema, consumo de recursos, puertos, procesos y estado de servicios.

## Objetivo

Este repositorio reúne scripts simples en Bash orientados a tareas comunes de diagnóstico y chequeo operativo en sistemas Linux.

Fue creado como parte de una etapa de aprendizaje enfocada en:

- administración básica de Linux
- revisión de procesos, memoria, CPU y disco
- inspección de puertos y procesos
- chequeo de servicios con systemd
- automatización básica con Bash
- uso de Git para versionado y documentación técnica
